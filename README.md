### Sobre mí

Estudiante de **Ingeniería Biomédica** (Universidad Politécnica de Sinaloa) enfocado en el cruce entre **procesamiento de señales, imagen médica y machine learning**. Me interesa particularmente convertir análisis exploratorios en resultados **estadísticamente honestos**: validación cruzada, corrección por comparaciones múltiples, y estar dispuesto a revisar una conclusión cuando los datos a mayor escala la contradicen.

- 🩻 Señales biomédicas (EMG) y su relación con variables fisiológicas
- 🧠 Imagen médica: entropía, FFT, transformada wavelet, segmentación
- 🤖 Clasificación con ML (SVM, Random Forest, Gradient Boosting) sobre features extraídas de señal/imagen
- 🖥️ Apps de escritorio en Python para adquisición de datos desde hardware (ESP32)
